# Telegram-бот Детского и Молодёжного Общественного Совета

Официальный Telegram-бот при Уполномоченном по правам ребёнка в Амурской области.

## Описание

Бот предоставляет функционал для:
- 📩 Приема обращений в Совет
- 📝 Подачи заявок на вступление в Совет
- ℹ️ Получения информации о Совете и его деятельности
- 👥 Просмотра состава руководства

## Структура проекта

```
telegram_bot/
├── __init__.py          # Инициализация пакета
├── bot.py               # Главный файл запуска бота
├── config.py            # Конфигурация и переменные окружения
├── messages.py          # Тексты сообщений
├── keyboards.py         # Клавиатуры бота
├── states.py            # Состояния FSM
├── utils.py             # Вспомогательные функции
└── handlers/            # Обработчики сообщений
    ├── __init__.py
    ├── common.py        # Общие команды (/start, меню)
    ├── appeal.py        # Обработка обращений
    ├── application.py   # Обработка заявок
    └── admin.py         # Ответы администраторов
```

## Установка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd <project-directory>
```

### 2. Установка зависимостей

```bash
pip install -r requirements-bot.txt
```

### 3. Настройка переменных окружения

Скопируйте файл `.env.example` в `.env`:

```bash
cp .env.example .env
```

Откройте `.env` и заполните следующие переменные:

```env
# Токен бота (получить у @BotFather в Telegram)
TELEGRAM_BOT_TOKEN=your_bot_token_here

# ID чата для обращений (групповой чат, отрицательное число)
APPEAL_CHAT_ID=-1002863620257

# ID чата для заявок на вступление (групповой чат)
APPLICATION_CHAT_ID=-1002692926810

# Опционально: таймауты и прокси
CONNECT_TIMEOUT=15.0
READ_TIMEOUT=15.0
# PROXY=socks5://localhost:9050

# Уровень логирования
LOG_LEVEL=INFO
```

### 4. Получение токена бота

1. Найдите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен в `.env`

### 5. Получение ID групповых чатов

Для получения ID группового чата:

1. Добавьте бота [@userinfobot](https://t.me/userinfobot) в ваш групповой чат
2. ID чата будет показан в формате `-100XXXXXXXXXX`
3. Скопируйте этот ID в соответствующие переменные `.env`
4. Удалите @userinfobot из чата

**Важно:** Не забудьте добавить вашего бота в оба групповых чата и дать ему права администратора для чтения сообщений!

## Запуск

### Запуск из корневой директории проекта

```bash
python -m telegram_bot.bot
```

### Запуск напрямую

```bash
cd telegram_bot
python bot.py
```

### Запуск в фоновом режиме (Linux)

```bash
nohup python -m telegram_bot.bot > bot.log 2>&1 &
```

### Использование systemd (рекомендуется для продакшена)

Создайте файл `/etc/systemd/system/telegram-bot.service`:

```ini
[Unit]
Description=Telegram Bot - Youth Council
After=network.target

[Service]
Type=simple
User=your_user
WorkingDirectory=/path/to/project
ExecStart=/usr/bin/python3 -m telegram_bot.bot
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Запустите сервис:

```bash
sudo systemctl daemon-reload
sudo systemctl enable telegram-bot
sudo systemctl start telegram-bot
sudo systemctl status telegram-bot
```

## Использование

### Для пользователей

1. Запустите бота командой `/start`
2. Выберите нужное действие из меню:
   - **📩 Обращение в Совет** - отправить вопрос или предложение
   - **📝 Заявка на вступление** - заполнить анкету для вступления в Совет
   - **ℹ️ Информация о Совете** - узнать о деятельности Совета
   - **👥 Руководство Совета** - посмотреть состав руководства

### Для администраторов

#### Ответы пользователям

Чтобы ответить пользователю:

1. В групповом чате найдите сообщение пользователя
2. Ответьте на него (Reply)
3. Бот автоматически отправит ваш ответ пользователю

#### Админ-панель (NEW! 🔥)

Администраторы имеют доступ к специальной панели управления ботом:

1. **Запуск админ-панели**: Отправьте команду `/admin` боту в личных сообщениях
2. **Возможности:**
   - 📝 **Редактирование текстов** - изменение всех текстовых сообщений бота через удобный интерфейс
   - 📊 **Статистика** - просмотр информации о количестве редактированных сообщений
   - 🔄 **Сброс текстов** - возврат к дефолтным значениям (отдельно или всех сразу)

3. **Как редактировать тексты:**
   - Откройте админ-панель через `/admin`
   - Нажмите "📝 Редактировать тексты"
   - Выберите нужное сообщение из списка
   - Нажмите "✏️ Редактировать"
   - Отправьте новый текст (поддерживается HTML-разметка)
   - Готово! Изменения применяются мгновенно

4. **HTML-разметка:**
   - `<b>текст</b>` - жирный
   - `<i>текст</i>` - курсив
   - `<code>текст</code>` - моноширинный шрифт

5. **Настройка администраторов:**
   - Узнайте свой Telegram ID через бота [@userinfobot](https://t.me/userinfobot)
   - Добавьте ID в файл `.env` в переменную `ADMIN_IDS`
   - Можно указать несколько ID через запятую
   - Перезапустите бота

**Важно:** Все изменения текстов логируются и сохраняются в файл `custom_messages.json`

## Логирование

Логи записываются в два места:
1. **Консоль** (stdout) - для мониторинга в реальном времени
2. **Файл bot.log** - для хранения истории

Уровни логирования (настраивается в `.env`):
- `DEBUG` - подробная информация для отладки
- `INFO` - основные события (по умолчанию)
- `WARNING` - предупреждения
- `ERROR` - ошибки
- `CRITICAL` - критические ошибки

## Обработка ошибок

Бот включает обработку следующих ситуаций:
- Проблемы с подключением к Telegram API
- Ошибки при пересылке сообщений
- Ошибки при удалении сообщений
- Невалидная конфигурация

Все ошибки логируются и не приводят к остановке бота.

## Безопасность

- Токен бота и ID чатов хранятся в `.env` (не коммитятся в Git)
- Все чувствительные данные загружаются из переменных окружения
- Файл `.env` добавлен в `.gitignore`

## Обновление

Чтобы обновить бота:

```bash
git pull
pip install -r requirements-bot.txt --upgrade
sudo systemctl restart telegram-bot  # если используется systemd
```

## Разработка

### Добавление новых обработчиков

1. Создайте новый файл в `handlers/`
2. Определите функцию `register_*_handlers(bot: TeleBot)`
3. Импортируйте и зарегистрируйте в `bot.py`

### Добавление новых состояний

1. Добавьте новое состояние в `UserState` в `states.py`
2. Создайте обработчик в соответствующем файле `handlers/`

### Изменение текстов

Все тексты сообщений находятся в `messages.py`

## Поддержка

При возникновении проблем:

1. Проверьте логи в `bot.log`
2. Убедитесь, что все переменные окружения установлены корректно
3. Проверьте, что бот добавлен в групповые чаты с правами администратора
