# Система управления Детским и Молодежным Общественным Советом

## Описание
Комплексная система для эффективного управления деятельностью Детского и Молодежного Общественного Совета при Уполномоченном по правам ребёнка в Амурской области.

Проект включает:
- 🌐 **Веб-приложение** - полноценная система управления
- 🤖 **Telegram-бот** - прием обращений и заявок (NEW!)

## Основные возможности

### 1. Управление членами совета
- Регистрация участников
- Профили с полной информацией
- Управление ролями и правами доступа
- История активности

### 2. Планирование мероприятий
- Календарь событий
- Создание и редактирование мероприятий
- Уведомления участников
- Учет посещаемости

### 3. Система голосований
- Создание опросов и голосований
- Анонимное и открытое голосование
- Просмотр результатов в реальном времени
- Архив голосований

### 4. Документооборот
- Загрузка и хранение документов
- Категоризация документов
- Поиск по документам
- Контроль версий

### 5. Управление проектами
- Создание инициатив и проектов
- Распределение задач
- Отслеживание прогресса
- Отчетность по проектам

### 6. Новости и объявления
- Публикация новостей
- Важные объявления
- Комментарии и обсуждения

### 7. Система обращений
- Приём обращений от детей и молодежи
- Категоризация обращений
- Отслеживание статуса
- Статистика

### 8. Отчетность
- Генерация отчетов о деятельности
- Статистика активности
- Экспорт данных

## Технологии
- **Backend**: Python 3.8+ / Flask
- **Frontend**: HTML5, CSS3, JavaScript
- **База данных**: SQLite (может быть заменена на PostgreSQL)
- **Аутентификация**: Flask-Login

## Установка и запуск

### Требования
```bash
python >= 3.8
pip
```

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Инициализация базы данных
```bash
python init_db.py
```

### Запуск приложения
```bash
python app.py
```

Приложение будет доступно по адресу: `http://localhost:5000`

## Первый вход
При первом запуске создается администратор по умолчанию:
- **Email**: admin@council.ru
- **Пароль**: admin123

⚠️ **Важно**: Обязательно смените пароль после первого входа!

## Безопасность
- Хеширование паролей (bcrypt)
- Защита от CSRF
- Валидация входных данных
- Ограничение размера загружаемых файлов
- Контроль доступа на основе ролей

## Роли пользователей
1. **Администратор** - полный доступ ко всем функциям
2. **Председатель совета** - управление мероприятиями, проектами, голосованиями
3. **Секретарь** - документооборот, протоколы
4. **Член совета** - участие в голосованиях, проектах
5. **Наблюдатель** - просмотр информации

## Отделы Совета
В Совете функционируют три отдела:

1. **Секретариат** - организационная работа, протоколирование заседаний
2. **Проектный отдел** - разработка и реализация социальных проектов
3. **Пресс-служба** - информационная поддержка, освещение деятельности

Каждый член совета может быть прикреплен к одному из отделов. Это позволяет:
- Организовывать работу по направлениям
- Просматривать статистику по отделам
- Фильтровать пользователей по отделам в административной панели
- Эффективно распределять задачи и ответственность

## Разработка
Проект использует Flask Blueprint для модульной архитектуры.

## 🤖 Telegram-бот (NEW!)

### Описание
Официальный Telegram-бот для приема обращений и заявок на вступление в Совет с админ-панелью для управления текстами.

### Возможности
- 📩 **Прием обращений** - граждане могут отправить свои вопросы и предложения
- 📝 **Заявки на вступление** - онлайн-анкета для желающих присоединиться к Совету
- ℹ️ **Информация о Совете** - актуальная информация о деятельности
- 👥 **Руководство** - состав руководства Совета
- 🔧 **Админ-панель** - управление всеми текстами бота через Telegram (команда `/admin`)

### Быстрый старт

**Требования:**
- Python 3.8+
- Токен бота от [@BotFather](https://t.me/BotFather)
- ID групповых чатов для обращений и заявок

### Админ-панель

Для доступа к админ-панели:
1. Узнайте свой Telegram ID через [@userinfobot](https://t.me/userinfobot)
2. Добавьте ID в `.env`: `ADMIN_IDS=123456789`
3. Отправьте боту команду `/admin`

**Функции админ-панели:**
- 📝 Редактирование всех текстов бота
- 📢 **Массовая рассылка** - отправка сообщений всем пользователям
- 📊 Статистика пользователей и сообщений
- 🔄 Сброс текстов к дефолтным значениям
- ✨ Поддержка HTML-форматирования

**Рассылка сообщений:**
1. В админ-панели нажмите "📢 Рассылка"
2. Отправьте сообщение (поддерживается форматирование)
3. Просмотрите предпросмотр
4. Подтвердите отправку
5. Получите статистику доставки
