## Начало работы

### Регистрация в системе

1. Перейдите на главную страницу системы
2. Нажмите кнопку "Регистрация"
3. Заполните форму регистрации:
   - Email (обязательно)
   - Пароль (обязательно, минимум 6 символов)
   - Фамилия, Имя (обязательно)
   - Отчество (опционально)
   - Телефон (опционально)
4. Нажмите "Зарегистрироваться"
5. После успешной регистрации войдите в систему

### Вход в систему

1. Нажмите кнопку "Вход"
2. Введите ваш email и пароль
3. Опционально: поставьте галочку "Запомнить меня"
4. Нажмите "Войти"

## Личный кабинет

После входа в систему вы попадаете в личный кабинет, где отображается:

- **Статистика вашей активности**:
  - Количество мероприятий
  - Количество проектов
  - Участие в голосованиях
  - Загруженные документы

- **Ближайшие мероприятия** - события, в которых вы участвуете

- **Мои задачи** - список задач, назначенных вам в проектах

- **Быстрые действия** - ссылки на основные разделы системы

## Мероприятия

### Просмотр мероприятий

1. Перейдите в раздел "Мероприятия" в главном меню
2. Вы увидите список всех предстоящих и прошедших мероприятий
3. Для каждого мероприятия отображается:
   - Название
   - Дата и время
   - Место проведения
   - Статус (запланировано, в процессе, завершено, отменено)
   - Количество участников

### Просмотр детальной информации

1. Нажмите на название мероприятия
2. Вы увидите полную информацию:
   - Подробное описание
   - Дата и время начала/окончания
   - Место проведения или онлайн-ссылка
   - Организатор
   - Список участников

### Регистрация на мероприятие

1. Откройте страницу мероприятия
2. Нажмите кнопку "Участвовать"
3. Вы будете добавлены в список участников

### Создание мероприятия (для администраторов и организаторов)

1. Перейдите в раздел "Мероприятия"
2. Нажмите "Создать мероприятие"
3. Заполните форму:
   - Название
   - Описание
   - Дата и время начала/окончания
   - Тип мероприятия
   - Место проведения
   - Онлайн-ссылка (если применимо)
4. Нажмите "Создать"

## Голосования

### Участие в голосовании

1. Перейдите в раздел "Голосования"
2. Выберите активное голосование
3. Ознакомьтесь с вопросом и вариантами ответов
4. Выберите один из предложенных вариантов
5. Опционально: оставьте комментарий
6. Нажмите "Проголосовать"

**Важно**: Голосовать можно только один раз. После голосования изменить свой выбор нельзя.

### Просмотр результатов

- Результаты завершенных голосований доступны всем участникам
- Результаты активных голосований доступны только администраторам
- Для каждого варианта отображается:
  - Количество голосов
  - Процент от общего числа

## Проекты

### Просмотр проектов

1. Перейдите в раздел "Проекты"
2. Вы увидите список всех проектов совета
3. Для каждого проекта отображается:
   - Название
   - Описание
   - Прогресс выполнения (%)
   - Статус (планирование, активный, завершен, приостановлен)
   - Количество участников и задач

### Работа с задачами

1. Откройте страницу проекта
2. В разделе "Задачи" вы увидите список всех задач проекта
3. Для каждой задачи отображается:
   - Название и описание
   - Ответственный
   - Срок выполнения
   - Приоритет
   - Статус

### Участие в проектах

- Вы можете быть добавлены в проект администратором или создателем проекта
- Участники проекта получают уведомления о новых задачах
- Вы можете просматривать прогресс проекта и выполнять назначенные задачи

## Документы

### Просмотр документов

1. Перейдите в раздел "Документы"
2. Вы увидите список всех документов, доступных членам совета
3. Для каждого документа отображается:
   - Название
   - Описание
   - Имя файла и размер
   - Дата загрузки
   - Пользователь, загрузивший документ

### Загрузка документа

1. Нажмите "Загрузить документ"
2. Заполните форму:
   - Название документа
   - Описание (опционально)
   - Категория (протокол, отчет, презентация, фото, другое)
   - Выберите файл
3. Нажмите "Загрузить"

**Ограничения**:
- Максимальный размер файла: 16 МБ
- Допустимые форматы: txt, pdf, doc, docx, xls, xlsx, jpg, jpeg, png, gif

### Скачивание документа

1. Найдите нужный документ в списке
2. Нажмите кнопку "Скачать"
3. Файл будет сохранен на ваше устройство

## Обращения

### Создание обращения

Любой человек (даже без регистрации) может создать обращение:

1. Нажмите "Обращения" в меню
2. Нажмите "Создать обращение"
3. Заполните форму:
   - Тема обращения
   - Категория (права ребенка, образование, здоровье, безопасность, другое)
   - Содержание обращения
   - Контактные данные (для незарегистрированных пользователей)
4. Нажмите "Отправить обращение"

### Отслеживание обращений

Зарегистрированные пользователи могут:
- Просматривать свои обращения
- Отслеживать статус рассмотрения
- Получать ответы от ответственных лиц

Статусы обращений:
- **Новое** - обращение только что создано
- **На рассмотрении** - обращение изучается
- **В работе** - принимаются меры по обращению
- **Решено** - обращение рассмотрено, даны ответы
- **Закрыто** - работа по обращению завершена

## Профиль

### Просмотр профиля

1. Нажмите на свое имя в правом верхнем углу
2. Выберите "Профиль"
3. Вы увидите свою информацию:
   - ФИО
   - Email
   - Телефон
   - Дата рождения
   - Роль в совете
   - Дата регистрации

### Редактирование профиля

1. На странице профиля нажмите "Редактировать"
2. Измените нужные поля:
   - ФИО
   - Телефон
   - О себе
3. Нажмите "Сохранить"

**Важно**: Email и роль могут быть изменены только администратором.

### Смена пароля

1. Перейдите в настройки профиля
2. Введите текущий пароль
3. Введите новый пароль (минимум 6 символов)
4. Подтвердите новый пароль
5. Нажмите "Сменить пароль"

---

## Роли пользователей

В системе предусмотрены следующие роли:

1. **Администратор** - полный доступ ко всем функциям системы
2. **Председатель совета** - управление мероприятиями, проектами, голосованиями
3. **Секретарь** - документооборот, протоколы заседаний
4. **Член совета** - участие в мероприятиях, голосованиях, проектах
5. **Наблюдатель** - просмотр информации без возможности голосования

## Часто задаваемые вопросы

**Q: Я забыл пароль. Что делать?**
A: Обратитесь к администратору системы для сброса пароля.

**Q: Могу ли я изменить свой голос после голосования?**
A: Нет, после отправки голоса изменить его нельзя.

**Q: Как стать членом совета?**
A: Для получения роли "Член совета" обратитесь к администратору после регистрации.

**Q: Можно ли удалить загруженный документ?**
A: Да, но только администраторы могут удалять документы.

**Q: Как долго рассматриваются обращения?**
A: Обращения рассматриваются в сроки, установленные законодательством.
